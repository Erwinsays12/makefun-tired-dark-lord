# The Tired Dark Lord

Entry for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/c/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) on make.fun.

`main.ts` writes a single 100-word monologue to `/output/entry.txt`, spoken by
a fantasy villain who is secretly just very tired. The tiredness is never
announced — it lives in the pauses, the deflections, and the paperwork: the
Dark Lord conquered the nine valleys and chained the river-god, yet what
derails him is tax letters about grain, a heavy sword, and a surrender form
in triplicate. The candles burn down, and so does he.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (100 words, under 600 characters).
